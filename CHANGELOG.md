# Changelog

## 1.0.0
- 2026-11-10: Published: Orca Cloud listing `3f3d02f5-8199-414c-9eaf-1f075a954aa6` and GitHub `barismert98/orcaslicer-line-art-studio`, release v1.0.0.
- 2026-11-10: First public version. Same behavior as 0.4.0.

## 0.4.0 (not published)
- 2026-11-10: Frame shapes: square, circle, rectangle, oval, rounded rectangle, hexagon. The picture, the line and the base follow the shape.
- 2026-11-10: Two-filament bases share vertices, so curved ones slice.
- 2026-11-10: Listing pictures from the real tab and slicer preview.

## 0.3.0 (not published)
- 2026-11-10: Automatic tone preparation, on by default; older jobs count as off.
- 2026-11-10: New defaults from the benchmark: detail spacing 1.3, contrast 1.25.
- 2026-11-10: Sliders with number fields for detail spacing, contrast and gamma. The tone card starts open.

## 0.2.0 (not published)
- 2026-11-09: `tools/benchmark.py`: the factory's art benchmark at fixed settings. The plugin itself is unchanged.
- 2026-11-09: New logo and tab icon, the line specimen chosen by the user.
- 2026-11-09: One-screen workbench tab in the OneLine family look: settings with advanced ones folded, picture, large preview, stats, a Before you slice list and a Save button always in view. Jobs and G-code output are unchanged.

## 0.1.0 (not published)
- 2026-11-09: Copied from Flow Line Art 1.0.1 and renamed. Flow-based modes, calibration and the flow multiplier removed.
- 2026-11-09: Built to the OneLine family rules: mode interface, job `mode`, own-object check.
- 2026-11-09: TSP line art: tone-driven points joined into one self-avoiding, constant-width line on a square base.
